# 🩸 BloodLife

A Full Stack Blood Donation Management System deployed on AWS EC2.

---

## 📌 Project Overview

BloodLife is a web-based Blood Donation Management System that helps connect blood donors with people in need during emergencies. The application allows users to register, log in securely, and search for blood donors based on blood group.

---

## 🚀 Features

- User Registration
- Secure Login Authentication
- Blood Donor Search
- Responsive User Interface
- MongoDB Atlas Database
- AWS EC2 Deployment
- Nginx Reverse Proxy
- PM2 Process Management
